ArgoCD Prod Architecture

Prod overlay composition & deployment to tenant-a (local) and tenant-b (remote) clusters

Overlay Patterns

  • • Infra: 3-layer Kustomize — base/ → prod/ → prod-tenant/{tenant}/
  • • Workloads: Multi-source Helm — directory scan + config.json + $values ref
  • • Infra path: apps/infrastructure/*/overlays/prod-tenant/{tenant}/
  • • Workload path: apps/workloads/*/overlays/prod/{tenant}/

Tenant Coverage

  • • Tenant-A (local): all 10 infra apps + tailscale-operator
  • • Tenant-B (remote): all 10 infra apps + tailscale-operator, immich, postgresql
  • • immich and postgresql are Tenant-B only
  • • tailscale-operator targets both tenants

Cluster Destinations

  • • Tenant-A: kubernetes.default.svc (local cluster, self-hosted)
  • • Tenant-B: 129.158.33.235:6443 (remote cluster)
  • • Shared AppProjects list both destinations
  • • Infra uses ServerSideApply=true; workloads do not
