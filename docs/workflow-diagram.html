Cluster Config — Architecture

Immich on K3s — Microservice Architecture with Tailscale, Sealed Secrets & Observability

Infrastructure Layer (L1–L3)

  • Traefik — ingress reverse proxy, terminates TLS
  • Cert-Manager — provisions Let's Encrypt certs for Traefik
  • Tailscale — operator + connector for Wireguard mesh and external S3 access
  • Sealed Secrets → Infra Secrets → Reflector — encrypted secret pipeline
  • Grafana Alloy — collects logs from PostgreSQL, Immich server & ML
  • New Relic — cluster-wide K8s metrics (pods, containers, nodes)

Workload Layer (L4)

  • Immich Server — photo management microservice API
  • Immich Machine Learning — CLIP / object detection inference
  • PostgreSQL — primary metadata store for Immich
  • Garage S3 — home network object store, accessed via Tailscale tunnel

Key Interactions

  • Ingress → Workload: Traefik routes HTTPS traffic to Immich Server
  • Secrets → Workload: Reflector mirrors secrets into workload namespaces
  • Workload → Infrastructure: Alloy pulls logs from all workload services
  • Workload → External: Immich accesses Garage S3 through Tailscale Connector
  • External → Cluster: Users access Immich via Traefik, or cluster via Tailscale
